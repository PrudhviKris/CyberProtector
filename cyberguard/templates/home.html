Detect cyberbullying before it does harm.

CyberGuard combines a classical TF-IDF model with a pretrained transformer to flag abusive messages, classify them into six categories, and show which words triggered the decision.

Analyze a message How it works
🧠

Hybrid AI model

TF-IDF + logistic regression trained on 17k labelled comments, combined with the Jigsaw-trained toxic-bert transformer.

🏷️

Six categories

Toxic, severe toxicity, obscene, threat, insult and identity hate, each with a severity level.

🔍

Explainable

Highlights the exact words that pushed the message toward "bullying".

⚙️

Built for scale

Batch CSV analysis, per-user history, an admin analytics dashboard and a REST API.
