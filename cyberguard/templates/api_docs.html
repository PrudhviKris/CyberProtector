REST API

Integrate CyberGuard into chat apps, forums or moderation tools. Every request needs an API key, which you can find on your {% if current_user.is_authenticated %}account page{% else %}account page (create an account){% endif %}.

Analyze one message

POST {{ request.host_url }}api/v1/analyze
X-API-Key: YOUR_KEY
Content-Type: application/json

{"text": "you are so stupid nobody likes you"}

Response:

{
  "label": "bullying", "is_bullying": true, "score": 0.93, "severity": "high",
  "top_category": "insult",
  "categories": {"toxic": 0.98, "insult": 0.91, "obscene": 0.12, "threat": 0.01, ...},
  "baseline_score": 0.88, "transformer_score": 0.98,
  "highlights": [{"token": "stupid", "weight": 0.31}, ...],
  "models": ["tfidf-logreg", "unitary/toxic-bert"]
}

Analyze many messages

{"texts": ["first message", "second message"], "explain": false}

Returns {"results": [...]}. Up to {{ config.BATCH_LIMIT }} texts per request.

Examples

curl -X POST {{ request.host_url }}api/v1/analyze \
  -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"text": "have a great day"}'
import requests
r = requests.post("{{ request.host_url }}api/v1/analyze",
                  headers={"X-API-Key": "YOUR_KEY"}, json={"text": "have a great day"})
print(r.json()["label"])

GET {{ request.host_url }}api/v1/health
